# 작은 도시 건축 시뮬레이터

설치 없이 브라우저에서 바로 실행할 수 있는 건축 시뮬레이터입니다.

## 실행 방법

`index.html` 파일을 브라우저로 열면 됩니다. 실행 중인 로컬 웹 서버를 사용하려면 [http://localhost:8000](http://localhost:8000)을 여세요. 직접 서버를 실행하려면 저장소 루트에서:

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 <http://localhost:8000> 을 여세요.

## 모드와 조작 방법

- **초보자 모드:** 14×14 지도, 시작 자금 ₩10,000.
- **일반 모드:** 22×22 지도, 시작 자금 ₩16,000, 높은 건설비와 운영비.
- 메뉴에서 건물을 고른 뒤 지도 타일을 눌러 건설합니다. 모드를 바꾸면 도시가 초기화됩니다.
- 태양광·화력·원자력 발전소가 전력을 공급합니다. 전력이 부족하면 주택 인구와 사업 수익이 줄어듭니다.
- 경공업·중공업·화학 공장은 전력과 유지비, 수익, 오염도가 서로 다릅니다.
- 주택은 일할 주민 30명을 제공하며, 상가·공장·광산·원전이 노동자를 고용합니다. 인력이 부족한 건물은 생산성이 낮아집니다.
- 우라늄 광산은 우라늄을, 희토류 광산은 희토류를 생산합니다. 원전은 우라늄을, 화학 공장은 희토류를 소비하므로 해당 광산을 먼저 운영해야 합니다. 남는 광석은 재고 24개를 넘으면 자동 판매됩니다.
- 지도에서 지어진 건물을 누르면 시간당 전력 사용·생산량, 고용 인원, 매출·원료 정보를 확인할 수 있습니다.
- 원전은 주택·상가·공원·화학 공장과 2칸, 화학 공장은 주택·공원과 1칸 이내에 지을 수 없습니다.
- 세율을 높이면 세입이 늘고 행복도는 낮아집니다. 철거하면 건설비의 40%를 돌려받습니다.
- 도시 운영을 시작하면 5초마다 하루가 지나며 세금, 사업 수입, 유지비가 정산됩니다.
